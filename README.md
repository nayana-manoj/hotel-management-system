# Hotel Management System

## Description

Hotel Management System is a DBMS project built for managing the daily operations of a hotel. It provides separate dashboards for admin and receptionist roles and connects a frontend interface with a Flask backend and PostgreSQL database.

## What It Does

- staff login with role-based access
- guest management
- reservation and check-in handling
- room type and room inventory management
- billing and payment tracking
- hotel service management
